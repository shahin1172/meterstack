# MeterStack – Multi-Tenant API Usage Billing System

MeterStack is a **production‑grade SaaS billing backend** that tracks API usage per tenant, generates invoices automatically, and provides real‑time dashboards. It is built with Django REST Framework, PostgreSQL, and Redis, and demonstrates the architecture and engineering practices expected of a production backend system.

---

## Features

- **Multi‑tenancy** – each tenant has isolated users, endpoints, and billing data
- **JWT authentication** with custom claims (tenant slug, user role)
- **Concurrency‑safe usage recording** using `select_for_update()`, atomic transactions, and a custom retry decorator with exponential backoff
- **Automated monthly invoicing** via management command, with duplicate prevention and budget alerts
- **Dashboard APIs** with caching (cache‑aside pattern) and ORM optimisations
- **Swagger documentation** auto‑generated by drf‑spectacular
- **Dockerised** development and production environment (Django, PostgreSQL, Redis, Gunicorn)
- **Defensive database design** – check constraints, unique constraints, composite indexes, and a functional index for time‑series queries
- **Type hints, structured logging, clean architecture, and a comprehensive test suite**
